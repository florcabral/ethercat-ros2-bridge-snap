EasyCAT demo runbook

Install the snap, display live A0/A1 values, publish ROS 2 joint states, and prepare the PlotJuggler or Foxglove recording.

Expected result: one command displays A0/A1 from 0–255 while publishing easycat_analog_0 and easycat_analog_1 on /joint_states.

The snap reads the Arduino's A0 and A1 analog inputs. For an interactive demo, two external potentiometers provide those input signals.

Prepare the hardware

  1. Connect the EasyCAT EtherCAT port to the host's configured EtherCAT adapter.
  2. Connect and power the Arduino/EasyCAT board.
  3. The standard EasyCAT shield has no built-in potentiometers. Connect two external linear potentiometers to the Arduino Uno:
    • potentiometer 1 center pin (wiper) to A0;
    • potentiometer 2 center pin (wiper) to A1;
    • one outer pin of each potentiometer to 5V and the other to GND.
  4. Wait a few seconds for the board and network adapter to initialize.

Open the project directory

cd ~/Documents/26.10/ethercat/ros2-ethercat-snap
ls -lh ethercat-ros2-bridge_0.1_amd64.snap

The expected artifact is ethercat-ros2-bridge_0.1_amd64.snap.

Verify the host EtherCAT master

The host supplies the IgH kernel modules and must expose /dev/EtherCAT0. The validated EasyCAT receive timeout is 5000 µs.

sudo ls -l /dev/EtherCAT0
sudo ethercat slaves

Expected slave description:

Generic 32+32 bytes rev 1
Do not continue if the slave is missing. Check board power, cable, selected adapter, IgH modules, and the 5000 µs timeout.

Install the ROS 2 content snap

snap list ros-lyrical-ros-base

If it is not installed:

sudo snap install ros-lyrical-ros-base --edge

Install the demo snap

sudo snap install --dangerous ./ethercat-ros2-bridge_0.1_amd64.snap

--dangerous is expected because this local artifact is not signed by the Snap Store.

Connect the interfaces

Connect the ROS content provider:

sudo snap connect \
  ethercat-ros2-bridge:ros-lyrical-ros-base \
  ros-lyrical-ros-base:ros-lyrical-ros-base

Connect access to the EtherCAT device:

sudo snap connect \
  ethercat-ros2-bridge:ethercat-master \
  ethercat-ros2-bridge:ethercat-master-slot

Verify all connections:

snap connections ethercat-ros2-bridge

The ROS content, EtherCAT, network, and network-bind plugs should all have connected slots.

Verify the bundled EtherCAT CLI

snap run ethercat-ros2-bridge.ethercat version
snap run ethercat-ros2-bridge.ethercat slaves

Expect IgH 1.6.9 and Generic 32+32 bytes rev 1.

Run the basic terminal demo

snap run ethercat-ros2-bridge.demo
  1. Wait for the status to change from WAITING FOR EASYCAT DATA to LIVE.
  2. Rotate potentiometer 1 and confirm A0 changes.
  3. Rotate potentiometer 2 and confirm A1 changes independently.
  4. Stop the demo with Ctrl-C.

Verify the ROS 2 topic

Leave the demo running and open a second terminal:

snap run ethercat-ros2-bridge.ros2 topic echo /joint_states

Expected shape:

name:
- easycat_analog_0
- easycat_analog_1
position:
- <A0 value>
- <A1 value>

Optionally inspect the rate:

snap run ethercat-ros2-bridge.ros2 topic hz /joint_states

The fixed mapping is position[0] = A0 and position[1] = A1.

Run PlotJuggler or Foxglove

  1. Keep the terminal demo running.
  2. Start PlotJuggler or Foxglove on ROS 2 domain 0.
  3. Select /joint_states.
  4. Plot /joint_states/position[0] and label it A0.
  5. Plot /joint_states/position[1] and label it A1.
  6. Rotate both potentiometers and confirm both curves respond.
The snap uses Fast DDS over UDPv4, so the host visualization tool can discover the topic without another bridge process.

Record the final video

Arrange the terminal dashboard, PlotJuggler or Foxglove, and a webcam view of the EasyCAT board on one screen. Start recording, rotate each potentiometer separately, then rotate both. Keep the physical movement, terminal values, and plotted curves visible together.

Troubleshooting

Waiting for data

Allow up to 15 seconds. Then inspect:

cat ~/snap/ethercat-ros2-bridge/current/easycat-demo.log

NO DATA - CHECK DEVICE/LOG

snap run ethercat-ros2-bridge.ethercat slaves
tail -n 100 ~/snap/ethercat-ros2-bridge/current/easycat-demo.log

BRIDGE STOPPED - CHECK LOG

tail -n 200 ~/snap/ethercat-ros2-bridge/current/easycat-demo.log
snap connections ethercat-ros2-bridge
sudo ls -l /dev/EtherCAT0
sudo ethercat slaves

PlotJuggler cannot see the topic

  1. Confirm the dashboard says LIVE.
  2. Run snap run ethercat-ros2-bridge.ros2 topic list.
  3. Use ROS domain 0 and remove any conflicting ROS_DOMAIN_ID.
  4. Restart PlotJuggler after starting the demo.

Fast rehearsal checklist

  • Board powered and cable connected
  • Host CLI sees the EasyCAT slave
  • Final snap installed
  • Required interfaces connected
  • Packaged CLI sees the slave
  • Dashboard reaches LIVE
  • A0 follows potentiometer 1
  • A1 follows potentiometer 2
  • /joint_states contains both values
  • Visualization shows both curves
  • Webcam and recording tested
